Use 1 for your local model, or choose up to 5. Applications use separate windows in your existing Jobot profile, keeping its logins and history. Jobot arranges its application windows so Simplify can keep filling visible pages. Lowering this number lets current applications finish before starting more.

Application time limit

Default: 30 minutes per application. Includes model calls and recovery; excludes time queued. At the limit, Jobot stops the application and moves on after cleanup. Saved changes apply to new applications.
